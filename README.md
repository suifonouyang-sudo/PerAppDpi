# PerAppDpi

按应用单独调整显示密度（DPI）的 Android 工具，并提供一个**悬浮窗**实时调节当前软件的 DPI。

> Android 系统本身没有「按包名设置密度」的接口，所有密度调节最终都通过 `wm density` 全局切换 + 前台应用监听来实现：切到某个应用就套用它专属的密度，切走就还原（跟随系统）。

## 功能

- **应用列表**：扫描本机可启动应用，逐个设置目标密度（步进 4 dpi，范围 80–1000），或设为「跟随系统」。
- **自动监控**：常驻前台服务监听当前应用，切换时自动套用/还原密度。
  - 识别方式：优先「使用情况访问」轮询（可经 Shizuku 自授权），也可启用无障碍服务实现即时切换。
- **悬浮窗**：在所有应用之上显示可拖动面板，实时显示当前前台应用名，用 `− / +` 现场调整该应用密度，`跟随系统` 一键还原。调整会同步写入该应用的按应用配置。
- **运行页**：Shizuku 授权引导、监控开关、悬浮窗开关、环境自检、内置日志。

## 权限要求

| 权限 | 用途 | 获取方式 |
| --- | --- | --- |
| Shizuku / Sui（`moe.shizuku.manager.permission.API_V23`） | 以 shell 身份执行 `wm density` | 在 Shizuku/Sui 管理器里手动允许本应用（App 内「运行」页触发标准授权弹窗） |
| 显示在其他应用上层（`SYSTEM_ALERT_WINDOW`） | 悬浮窗 | 系统设置，App 内引导跳转 |
| 使用情况访问（`PACKAGE_USAGE_STATS`） | 识别当前前台应用（轮询模式） | 系统设置，App 内引导跳转；或经 Shizuku 自授权 |
| 无障碍服务（可选） | 极速模式，切换即时生效 | 系统无障碍设置 |
| 前台服务（specialUse） | 常驻监听 | 自动 |

> 说明：你设备上的 Shizuku 变体若为 **Sui**（root 版），它没有 adb 授权通道，必须在其管理器界面点一次允许；这是所有 Shizuku 应用的标准步骤。

## 使用步骤

1. 安装并运行 Shizuku 或 Sui，启动其服务。
2. 打开本 App → 「运行」页：开启监控/悬浮窗，按提示授予 Shizuku、悬浮窗、使用情况访问权限。
3. 在「应用」页为常用应用设定密度；或直接用悬浮窗 `−/+` 现场调。

## 构建

需要 Android SDK（API 34 平台）+ JDK 17+ + Gradle 8.7（已随 wrapper 提供）。

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 下载

release 中提供已签名的 debug APK，可直接安装到 Android 11+ 设备试用。
